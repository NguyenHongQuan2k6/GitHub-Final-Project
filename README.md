# Simple Interest Calculator

A simple Bash script that calculates **simple interest** from user input.

## Formula

```
Simple Interest = (Principal × Rate × Time) / 100
```

## Inputs

| Field | Description |
|---|---|
| Principal | The initial amount of money |
| Rate of interest | The annual interest rate (in %) |
| Time period | The duration in years |

## Usage

```bash
chmod +x simple-interest.sh
./simple-interest.sh
```

Enter the principal, rate of interest and time period when prompted. The script prints the simple interest.
